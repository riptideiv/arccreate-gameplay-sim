# 中文化维护与验证

项目默认简体中文，页首语言选择器保留 English，入口说明保留 [README.en.md](../README.en.md)。项目自有 Markdown 使用中文；源码标识、命令、谱面元数据、JSON／日志等技术产物及第三方文档／许可证保留原文。ArcCreate 游戏画面不是网页文字，本分支不改变游戏内字体或语言。

## 实现

- `dashboard/i18n-messages.js`：简体中文消息表，英文原文作为稳定键。专有歌曲名、单位与机器值不翻译。
- `dashboard/i18n.js`：显示翻译、格式模板、静态文本／属性绑定、语言保存与即时切换。默认 `zh-CN`；浏览器保存键 `rhythm-workbench.language`，英文值 `en`。存储受限时仍可在当前页面切换。
- HTML 静态文本启动时绑定原文本节点，不替换父节点；输入框、SVG 和视频不重建。ARIA、标题和占位符同样保留英文源。
- 动态文字统一通过 `setText(element, englishSource)`，动态可访问属性用 `setAttributeText(element, name, englishSource)`。切换从英文源重算，因此中英往返不丢原文；从 DOM 读回已译文本再翻译会造成错误。
- 格式消息显式使用 `{count}` 等占位符，并限制数字参数形状，避免一个计数吞掉整行状态。` · ` 组合状态逐块处理。纯文本赋值，不把谱名／错误当 HTML。
- 选择器在渲染表单之外，不进入设置、API、计划／姿态／媒体缓存键。切换不发生成请求、不选别的演奏、不重新加载视频、不重置播放速度或进度。已完成视频不因语言改变失效。
- 服务静态白名单包含两个翻译模块；发布时必须同时部署，不能只更新 HTML／app。

新增文字时在目录补齐中文。新动态状态要绑定显示出口；引擎错误和取消判断仍保留内部英文语义，只在显示时翻译。未识别的底层错误详情保留原文，便于诊断。不得把翻译写回原始 `run.json`、谱面或规划数据。

## 自动检查

```sh
node tests/test_i18n.mjs
node tests/test_preview_recorder.mjs
.venv/bin/python -m pytest tests vendor/arc-hand-order/tests -q
```

翻译测试覆盖静态 HTML／可访问名称、数字模板、中英占位符一致、组合状态、原值保留和普通文本安全。录制器测试保证录制／取消／音频图复用与状态恢复未退化。Python 现有规划／媒体／服务测试继续运行。

## 浏览器检查

使用独立测试标签，不打断用户活动页面；默认中文，检查真实保存演奏的曲库、范围、设置、原生结果、动作统计、错误和导出状态。切到英文再切回，比较谱面 ID、所有表单值、所选演奏、视频源、播放时间／速度及 canvas，确认未重置。选择应在刷新后保留。

桌面及手机宽度检查语言选择、长中文提示、播放控件、底部导航和导出按钮，不允许横向溢出或遮住画面。手机尺寸模拟仅验证布局，不代表真机性能。用已有短演奏检查实际导出／取消的状态文字，不要为了翻译验证重跑规划或 ArcCreate。

2026-11-07 中文化验证：175 项 Python 测试通过；332 条消息的 Node 翻译目录／模板／HTML／ARIA 检查与原录制器回归通过。浏览器证据和检查结果保存在本机 `output/i18n-qa/`。旧服务对白名单外模块返回 404，等活动演奏完成才重载服务；未取消运行中的规划或原生渲染。
