# 双臂交叉规划

触点搜索仍在计分点上运行。对于每个候选分配，规划器用同一套手部移动曲线，检查两个计分点之间的整段路径。状态记录双臂未交叉、右臂在上或左臂在上。横向顺序真正恢复后才结束交叉，横坐标相等的一帧不会重置状态。搜索合并候选时也比较交叉顺序与尚待补齐的移动轨迹。

从另一触点的屏幕上方通过时，该手必须走上层。从下方通过时可保留上下两种路线。双手在交叉期间必须保持原有层次，直到真正分开。同一段移动可以先分开，再以另一种层次交叉。

计分触点之间的空中移动保留直达路线，并尝试从另一触点的屏幕近侧绕行。规划器会尝试两种宽度的绕行路线，并检查两端触点、手指按住的帧和速度限制。

上层食指按住屏幕时，如果交叉路线会使它与另一触点的指尖投影重叠，规划器会淘汰该候选。这个检查使用已知的触点约束；需要具体臂部姿态才能判断的情况仍由三维求解处理。

新触点文件的 `arm_crossings.routes` 记录每段交叉的起止帧与上方手臂，`arm_crossings.travel` 保存选中的离屏绕行采样。动作求解固定肩部支点，先搜索肩部转动、肘部摆动和松手后的抬升，再尝试用手腕补偿。上臂和前臂的碰撞胶囊均使用 20 mm 半径。上层手本身在投影重叠时必须从另一条手臂上方通过。求解器检查插值帧，并在无法留出间隙时报告时间和手臂。原生回放沿用触点与判定规则。

这套规则约束单段交叉期间的上下顺序。不同交叉之间的相对平面角度仍可能累计一整圈。评估时可分别检查指尖轨迹和实际袖口轨迹。历史演奏保留原来的动作，重新生成预览即可应用交叉规划。
